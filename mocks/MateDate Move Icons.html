01

The family

Eight grades on one severity ladder. Each glyph is a white knockout on a disc tinted with the move's semantic color — the shape alone carries meaning, so the set still reads in grayscale or at a glance. The old monospace glyphs are kept as a fallback label.

02

The new checkmate states

Unlike per-move grades, checkmate is terminal — it ends the game. Both icons swap the abstract glyph for a loaded, on-theme mark: the crown (you converted the king — you landed the date) and the broken heart (you got mated — the date unmatched you).

Win · Checkmate

You landed the date

Interest converted to a real plan. The crown = the king is yours; the match is on the board.

Lose · Checkmate

The date unmatched you

Game over on their move. The broken heart is the only verdict the engine gives that can't be recovered.

05

How to use

Define the symbol library once per page, then reference any icon with <use>. Size with CSS on the wrapper; recolor with a single color property.

1 · Paste the <svg><defs>…</defs></svg> symbol block once, near the top of the page.

2 · Reference an icon anywhere — set size + color on the wrapper:

<!-- 40px Brilliant -->
<span class="mv-icon i-brilliant" style="width:40px;height:40px">
  <svg><use href="#mv-brilliant"/></svg>
</span>

/* the disc reads `currentColor`, so one rule recolors it */
.i-brilliant { color: var(--m-brilliant); }
